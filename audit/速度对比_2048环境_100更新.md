# 2048 环境 × 100 更新速度实测

Newton/MJWarp 稳态吞吐为本地 Instinct/PhysX 的 **1.423 倍**，每次更新耗时减少 **29.7%**。

| 指标 | Newton/MJWarp | Instinct/PhysX |
|---|---:|---:|
| 预热后吞吐（transitions/s） | 16,041 | 11,270 |
| 预热后每次更新（秒） | 3.064 | 4.361 |
| 其中采样阶段（秒） | 2.068 | 3.525 |
| 其中学习阶段（秒） | 0.996 | 0.836 |
| 100更新采样+学习日志计时（秒） | 343.60 | 437.21 |
| 本次进程总墙钟时间，含初始化/退出（秒） | 404.65 | 522.68 |
| 设备采样显存峰值（GiB） | 11.11 | 14.14 |

两边均从头训练2048环境×24步rollout×100更新，共4,915,200 transitions；单GPU串行运行，seed42、完整10×20地形、无视频、原PPO/AMP网络。稳态统计统一剔除前10次，使用后90次。吞吐为该阶段总样本数除以日志记录的采样+学习总时间。

这是现有两套完整实现的速度对照，包含Python/PyTorch版本、感知、AMP和物理后端差异，不能全部归因为求解器。Newton为Lab3.0/PyTorch2.11，PhysX为原Instinct环境Lab2.3.2/Sim5.1/PyTorch2.7。两边初始化回合长度行为沿用各自入口默认值。

PhysX使用启动参数将缺失的默认AMP路径指向同一官方NPZ，并去掉G1不具备的head_*奖励关节匹配；没有禁用该奖励、修改原工程源代码或减少环境数。前两次启动失败日志保留，均未进入训练，不计入成功运行的耗时。

显存为0.5秒间隔设备总占用采样，包含约573MiB桌面等占用，是实际峰值下界。两边完整100次更新成功退出，模型和日志保留。
